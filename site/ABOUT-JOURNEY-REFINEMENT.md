# About timeline — The Unfolding Journey

## Why change it

The first version has the right content but a familiar alternating-card silhouette. The user's annotated review calls for a winding path and a more expressive visual story. This refinement changes only the About timeline, not the other V3 pages.

## Composition selected

Three approaches considered:

1. Horizontal cinematic panels: immersive, but requires sideways navigation and hides the chronology.
2. A geographic map: strong travel association, but education, marriage and career events do not all have verified coordinates. A map would imply information we do not have.
3. **An unfolding illustrated route:** a serpentine line joins generous editorial scenes. Large type and event-specific vector compositions replace repeated boxes. This best matches the sketch while keeping a natural vertical reading order.

Desktop pairs each milestone's text with an oversized illustrated waypoint, alternating the visual weight. A quiet route bends through the waypoint and returns to the centre before the next scene. Personal and professional chapters remain separate so their ordering does not pretend to be a verified merged chronology.

## Visual vocabulary

- Birth: a sunrise / landscape vignette and origin marker.
- Education: graduation and layered document geometry; BTech and MTech retain distinct labels.
- Australia: a plane / globe composition, not an invented flight track.
- Delhi: an architectural silhouette and return marker.
- Marriage: intertwined rings and heart.
- Engineering: a terminal/code composition.
- Business: architectural blocks.
- Film/open source: a frame and play motif.
- Leadership: a launch/orbit composition.

All graphics are decorative HTML/SVG with existing Lucide icons, not factual maps or quantitative charts. No new image or animation dependency.

## Motion and interaction

Each visible route segment draws once, followed by a brief illustration and text entrance. No looping traveller, pulse, parallax, scroll hijack or continuous scrub. Links remain ordinary keyboard-accessible anchors. Reduced motion and no JavaScript show the complete static journey.

## Mobile composition

Use a narrow winding rail on the left and a compact illustrated scene above each milestone's text. Do not shrink the desktop two-column scene. Check 320, 360, 390, 768 and 1440px, plus keyboard, reduced motion and no-JS readability.

## Content and acceptance

Retain existing events, links and chapter anchors. Personal years remain absent until the author supplies them. The geometry expresses narrative order, not distance, elapsed time or travel routes. Review real browser screenshots before handing off; run typecheck, unit tests, production build and relevant browser regressions.
